My Portfolio

Welcome to My Portfolio, a personal portfolio website built to showcase projects, development skills, and my journey as a developer.

Live Demo: "View My Portfolio" (https://myportogw-two.vercel.app/)

Overview

My Portfolio is a web project designed to present personal information and development work through a modern web interface. Built with React and Vite, this project serves as a foundation for showcasing projects, skills, and professional experience.

Tech Stack

- React — Building interactive user interfaces.
- Vite — Fast development server and production build tooling.
- JavaScript — Application logic.
- HTML5 & CSS3 — Web structure and styling.
- Node.js — Development environment and test tooling.

Getting Started

Follow these steps to run the project locally.

Prerequisites

Make sure you have installed:

- "Node.js" (https://nodejs.org/)
- npm (included with Node.js)
- "Git" (https://git-scm.com/)

Installation

1. Clone the repository

git clone https://github.com/Fariqueueueee/myportogw.git

2. Navigate to the project directory

cd myportogw

3. Install dependencies

npm install

4. Start the development server

npm run dev

5. Open the local URL

Open the URL displayed in your terminal, usually:

http://localhost:5173

Available Commands

Command| Description
"npm run dev"| Start the development server
"npm run build"| Build the production version
"npm run preview"| Preview the production build
"npm test"| Run the project's tests

Deployment

This project is deployed on Vercel.

Visit the live website:

"myportogw-two.vercel.app" (https://myportogw-two.vercel.app/)

To deploy your own version, connect the repository to "Vercel" (https://vercel.com/) and configure the build command as "npm run build".
